# TWBI Dashboard — ดัชนีความอยู่ดีมีสุขของประชากรและสังคม รายจังหวัด

แดชบอร์ดแบบ interactive ของ **Thailand Well-Being Index of the Population and Society (TWBI)** ครอบคลุม 77 จังหวัด 5 มิติ 22 ตัวชี้วัด

## หน้าต่าง ๆ

| แท็บ | เนื้อหา |
|---|---|
| ภาพรวม | แผนที่ประเทศไทยระบายสีตามคะแนน, อันดับ 77 จังหวัด, โปรไฟล์จังหวัดพร้อมกราฟใยแมงมุม 5 มิติ, ค่าเฉลี่ยรายเขตสุขภาพ, ตารางคะแนนรายมิติ |
| บทวิเคราะห์จังหวัด | บทสรุปอัตโนมัติ, ตำแหน่งเทียบประเทศ/เขต, จังหวัดที่คล้ายกัน, ลำดับความสำคัญพร้อมตัวจำลองคะแนน, ตาราง 22 ตัวชี้วัด |
| เจาะลึกตัวชี้วัด | กราฟแปลงค่าจริงเป็นคะแนน, การกระจายของ 77 จังหวัด, การคำนวณแบบแทนค่า |
| วิธีคำนวณ | สูตรคะแนนมาตรฐาน 25–100, กรณีพิเศษตัวชี้วัด 4.4, การถ่วงน้ำหนัก, เครื่องคำนวณ |
| แหล่งข้อมูล | ตัวชี้วัด เกณฑ์ W/B ปีข้อมูล และหน่วยงานต้นทาง |

## โครงสร้างไฟล์

```
index.html                     หน้าแดชบอร์ด (ไฟล์เดียวจบ ข้อมูลฝังอยู่ในไฟล์)
data/TWBItableau.csv           ข้อมูลต้นฉบับจากไฟล์ TWBItableau.xlsx
data/twbi_provinces.json       ข้อมูลที่ใช้ในแดชบอร์ด (ค่าจริงและคะแนนรายจังหวัด)
data/thailand_map_paths.json   เส้นขอบจังหวัดสำหรับแผนที่ (SVG path)
.nojekyll                      ให้ GitHub Pages เสิร์ฟไฟล์ตรง ๆ
```

`index.html` ไม่ต้องใช้ไฟล์ใน `data/` ในการแสดงผล เปิดไฟล์ในเบราว์เซอร์ได้ทันทีแม้ไม่มีอินเทอร์เน็ต (ยกเว้นฟอนต์ Google Fonts ที่จะใช้ฟอนต์สำรองแทน) โฟลเดอร์ `data/` มีไว้ให้ตรวจสอบหรือนำไปใช้ต่อ

## วิธีเผยแพร่บน GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `twbi-dashboard` (ตั้งเป็น Public หากใช้บัญชีฟรี)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปที่ branch `main` (กด **Add file → Upload files** แล้วลากไฟล์ทั้งหมดรวมทั้งโฟลเดอร์ `data`)
3. ไปที่ **Settings → Pages**
4. ที่ **Build and deployment → Source** เลือก **Deploy from a branch**, Branch `main`, โฟลเดอร์ `/ (root)` แล้วกด **Save**
5. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/twbi-dashboard/`

หรือใช้คำสั่ง git:

```bash
git init
git add .
git commit -m "TWBI dashboard"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/twbi-dashboard.git
git push -u origin main
```

## วิธีคำนวณโดยย่อ

- ตัวชี้วัดทางบวก: `Score = 25 + [(X − W) / (B − W)] × 75`
- ตัวชี้วัดทางลบ: `Score = 25 + [(W − X) / (W − B)] × 75`
- ตัดเพดานที่ 100 และพื้นที่ 25 · ตัวชี้วัด 4.4 ชั่วโมงทำงานใช้ช่วงเหมาะสม 38–44 ชม.
- คะแนนมิติ = ค่าเฉลี่ยตัวชี้วัดในมิติ · คะแนน TWBI = ค่าเฉลี่ย 5 มิติ

## แหล่งข้อมูลและการอ้างอิง

- ปรีดา แต้อารักษ์ และ ทัสนันทน์ สัตย์ฌุชนม์. *ดัชนีความอยู่ดีมีสุขของประชากรและสังคม (TWBI)*. พิมพ์ครั้งที่ 1. นนทบุรี: สำนักงานคณะกรรมการสุขภาพแห่งชาติ (สช.), 2569. ISBN 978-616-569-052-2 — เนื้อหาอนุญาตให้ใช้เพื่อประโยชน์ทางวิชาการ ไม่ใช่เพื่อการค้า โดยต้องอ้างอิงแหล่งที่มา
- เว็บไซต์ TWBI: https://infocenter.nationalhealth.or.th/twbi/
- ขอบเขตจังหวัด: [apisit/thailand.json](https://github.com/apisit/thailand.json) (ปรับลดรายละเอียด ใช้เพื่อการแสดงผล ไม่ใช่ขอบเขตทางการ)
- "เขต" ในข้อมูลคือเขตสุขภาพ 1–13 ของกระทรวงสาธารณสุข (เขต 13 = กรุงเทพมหานคร)

ตัวชี้วัดแต่ละตัวใช้ข้อมูลต่างปีกัน (พ.ศ. 2564–2568) บทวิเคราะห์รายจังหวัดสร้างอัตโนมัติจากตัวเลขในข้อมูล เป็นการบรรยายสถานะ ไม่ได้อธิบายสาเหตุ
